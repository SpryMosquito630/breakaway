The additions use 500px Commons thumbnails. Mbappé, Salah and Koundé were recompressed as optimized JPEGs at quality 78; all other additions retain the downloaded pixels. Existing source crops are identified in their source titles. Runtime cover cropping may create an adapted image; retain each image’s stated share-alike license for such adaptations. The image licenses do not relicense unrelated app source code.

All additions require attribution; all except the CC BY 2.0 Trent Alexander-Arnold photograph also require share-alike licensing. Preserve the source and license links and indicate resizing, compression and cropping. The API metadata flags personality rights for fifteen additions; the copyright licenses do not establish a model release or player endorsement. The Trent source is credited to Eric The Fish from UK; its Flickr original was verified CC BY 2.0 by FlickreviewR 2 on June 4, 2019, as recorded on the original Commons file page. Other new sources declare the photographer’s own work.

For face visibility in the 250px-tall portrait carousel, use a top-biased cover position (approximately horizontal 50%, vertical 15%, or `top`). Every added player has a visible face in the source portrait.
