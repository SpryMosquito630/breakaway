## Boundaries and remaining checks

- The working folder contains pre-existing untracked duplicate `* 2.*` files, including duplicate drill images. These were preserved. They cause a media-uniqueness test to fail when the whole unfiltered folder is tested; the clean tracked-file suite and GitHub CI pass. They were not committed or deleted.
- Simulator inspection worked, but native interaction failed because the control service reported no available window. **Physical iPhone silent-switch audio, haptics, screen locking/background timing and OS notification delivery remain unverified.** Browser tests and pure clock tests do not prove these behaviors.
- The native Expo Go private-link handoff still needs a device check. Browser private-link restoration was verified without sending an AI request.
- If both SecureStore deletion and fallback writing fail, erasure across a physical app restart cannot be guaranteed. The connection is blocked in the current session and the app reports the failure.
- `npm audit` reports a moderate transitive `minimatch` advisory under Expo fingerprint tooling. Its suggested force fix would downgrade Expo to SDK 52, so that incompatible downgrade was not applied.
- No App Store submission, TestFlight upload, real user video, or personal training history was used for this audit. Five-tab Expo preview remains; laptop-backed Coach/Analyze remain excluded from release destinations.
